# Affiliate video — "Buku Pertama"

HyperFrames edit of a 20.8s affiliate video (How to Talk to Anyone + The Psychology of Money).
**Status: preview only — not rendered yet.**

- `video/index.html` — the HyperFrames composition (generated by `scripts/build_composition.py`; edit timings there and re-run).
- `video/preview.html` — browser preview harness (plays the composition with the VO + SFX, no render).
- `video/data/transcript.json` — word-level transcript of the cleaned voice over (Whisper large-v3, hand-corrected).
- `video/assets/vo_final.wav` — cleaned VO (denoise, de-ess, -14 LUFS, pauses removed: 23.7s → 20.8s).
- `video/assets/proxy/` — 540x960 preview proxies. Full-res footage: `scripts/fetch_footage.sh`.

Render locally when approved (free, no cloud credits): `cd video && npx hyperframes render -o out.mp4`.

## House style

The editing style is saved as a Claude Code skill: `.claude/skills/affiliate-video-edit/SKILL.md`.
Ask for a new affiliate video "same style as buku final" and it is applied automatically.
